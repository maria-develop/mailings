# Система управления рассылками на Django

Этот проект предназначен для управления email-рассылками, включая администрирование 
получателей, планирование и отслеживание попыток отправки. 


## Функционал

1. **Управление клиентами**:

    **Модель «Получатель»**:
    - `Email`: Строка, уникальное значение.
    - `Ф.И.О.`: Строка.
    - `Комментарий`: Текстовое поле.

2. **Управление сообщениями**:

    **Модель «Сообщение»**:
    - `Тема`: Строка.
    - `Тело`: Текстовое поле.

3. **Управление рассылками**:

    **Статусы рассылки**:
    - `Создана`: рассылка создана, но не отправлена.
    - `Запущена`: рассылка отправлена хотя бы один раз.
    - `Завершена`: окончание срока действия рассылки.

    **Модель «Рассылка»**:
    - `Дата и время начала`: Дата и время.
    - `Дата и время окончания`: Дата и время.
    - `Статус`: Строка (`Создана`, `Запущена`, `Завершена`).
    - `Сообщение`: Внешний ключ на модель «Сообщение».
    - `Получатели`: Связь «многие ко многим» с моделью «Получатель».

4. **Ручная отправка рассылок**.

5. **Попытки отправки рассылок**:

    **Модель «Попытка»**:
    - `Дата и время`: Дата и время.
    - `Статус`: Строка (`Успешно`, `Не успешно`).
    - `Ответ сервера`: Текст.
    - `Рассылка`: Внешний ключ на модель «Рассылка».

6. **Главная страница**: Отображает количество всех рассылок, количество активных рассылок и количество уникальных получателей.

7. **Регистрация и аутентификация пользователей**:
    - регистрация пользователей с подтверждением email.
    - вход и выход из системы, восстановление пароля.

8. **Статистика и отчеты**:
    - количество успешных и неуспешных попыток отправки рассылок.
    - данные по отправленным сообщениям.

9. **Ограничение доступа**:
    - Пользователи могут управлять только своими рассылками и клиентами.
    - Менеджеры имеют доступ к просмотру всех рассылок и клиентов, а также могут просматривать список пользователей, блокировать их и отключать рассылки.

    **Роли**:
    - **Пользователь**:
        - Создание, просмотр, редактирование и удаление своих клиентов и рассылок.
        - Просмотр статистики по своим рассылкам.
    - **Менеджер**:
        - Просмотр всех клиентов и рассылок.
        - Управление доступом пользователей и статусами рассылок.

10. **Кеширование**:
    - серверное и клиентское кеширование для повышения производительности.

## Начало работы

### Требования
- Python 3.12
- Django 4.2.2

### Установка
1. Клонируйте репозиторий.
   ```bash
   git clone https://github.com/maria-develop/mailings
   
2. Настройте виртуальное окружение poetry и установите зависимости.

3. Примените миграции для настройки базы данных.
     python manage.py migrate

4. Создайте суперпользователя для доступа к админке.

5. Запустите сервер разработки.

### Использование
1. Админ-панель доступна по адресу http://127.0.0.1:8000/admin/ для управления пользователями и правами.
2. Войдите как пользователь или менеджер для доступа к различным уровням функциональности.

## Возможности
CRUD-операции: Управление клиентами, сообщениями и рассылками.
Ручная отправка рассылок: Отправка рассылок по требованию.
Отчеты и статистика: Отслеживание попыток, успешных и неуспешных отправок.
Роли и права доступа: Контроль доступа для пользователей и менеджеров.
Кеширование: Повышение производительности за счет серверного и клиентского кеширования.
